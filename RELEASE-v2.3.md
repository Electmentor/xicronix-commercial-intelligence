# Xicronix Commercial Intelligence — V2.3

Fecha: 18 de septiembre de 2026.

## Objetivo

Convertir la ficha del prospecto en el centro operativo de la venta y separar claramente:
- madurez comercial por hitos;
- potencial calculado;
- movimientos ocurridos;
- tareas y siguientes acciones.

## Seis hitos de madurez

1. M1 — Prospecto identificado y calificado — 15%
2. M2 — Necesidad y alcance definidos — 30%
3. M3 — Propuesta presentada — 50%
4. M4 — Negociación y validación comercial — 70%
5. M5 — Compromiso formal del cliente — 85%
6. M6 — Venta cerrada — 100%

La madurez no aumenta por cantidad de correos, llamadas o reuniones. Solo movimientos definidos como evidencia de hito pueden avanzar el porcentaje.

## Movimientos estructurados

Cada movimiento separa:
- acción realizada;
- canal;
- resultado;
- necesidad / horizonte / señal de presupuesto;
- evidencia o referencia;
- notas;
- fecha y hora de ocurrencia;
- fecha de registro;
- próxima acción y fecha de seguimiento.

El menú cubre atención, calificación, reuniones, diagnóstico, propuestas, negociación, formalización, pagos, ejecución y cierre.

## Ficha maestra

La vista de cada prospecto muestra:
- institución y contacto;
- necesidad;
- canal de origen;
- estado;
- madurez e hito actual;
- potencial calculado como indicador independiente;
- presupuesto estimado;
- siguiente acción;
- tareas pendientes;
- línea cronológica de movimientos.

Acciones directas:
- Editar prospecto
- Registrar movimiento
- Crear tarea

## Integridad de datos

La base de datos aplica el avance del hito de forma transaccional desde movimientos estructurados. Un movimiento que no acredita un hito queda documentado sin elevar la madurez.

La solicitud real del Colegio María de las Mercedes se conserva como único prospecto operativo y se inicia en M1 / 15%, respaldada por la solicitud comercial original. No se añadió una interacción ficticia para justificar el porcentaje.

## Fuera de alcance de V2.3

Esta versión todavía no implementa:
- agenda/calendario;
- carpeta documental;
- control de pagos;
- notificaciones nuevas;
- respuesta desde el CRM;
- integración completa de correo o WhatsApp;
- prioridad dinámica.

Esos módulos se conectarán posteriormente al núcleo comercial ya estructurado.
